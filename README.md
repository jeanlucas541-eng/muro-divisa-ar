# Muro de divisa — visualizador BIM e realidade aumentada

Visualização pública ilustrativa do modelo R11. Não constitui projeto executivo, validação estrutural ou locação de obra.

No iPhone, abra `ar.html` no Safari, escolha Muro completo ou Armaduras e toque em Colocar no ambiente. Use mesa ou piso bem iluminado, mova lentamente o aparelho para reconhecer a superfície e ajuste a maquete com gestos. Não precisa imprimir marcador.

O modo marcador está em `marker.html` e é opcional. O visualizador principal inclui caminhada simulada.

Somente geometria de apresentação e bibliotecas do visualizador: não inclui RVT, desenhos, logs ou documentos de origem.

Teste real no iPhone ainda pendente.
